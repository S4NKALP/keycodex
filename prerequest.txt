KEYCODEX - SYSTEM PREREQUISITES
===============================

Neovim 0.12 or newer - the config uses vim.pack, vim.pack.UI and
vim.lsp.config. Check with:

  nvim --version

Two kinds of dependencies:
  * system tools - install with your package manager (listed below)
  * editor tooling - installed on first launch by Mason and nvim-treesitter,
    from the lists in lua/extensions.lua

Quick install
-------------
Arch:

  sudo pacman -S --needed git curl tar unzip gcc make ripgrep fd wl-clipboard \
    nodejs npm python python-pip rustup clang go luarocks \
    imagemagick ghostscript tectonic

Debian/Ubuntu:

  sudo apt install git curl tar unzip gcc make ripgrep fd-find nodejs npm \
    python3 python3-pip cargo clang golang-go luarocks wl-clipboard \
    imagemagick ghostscript

  fd-find installs the binary as `fdfind`; symlink it once:

    ln -s "$(command -v fdfind)" ~/.local/bin/fd

  tectonic is not packaged there - skip it, or install from
  https://github.com/tectonic-typesetting/tectonic/releases if you want
  Snacks.image to render LaTeX.

Required for everyone
---------------------
- git               clone and update plugins (vim.pack)
- curl, tar, unzip  download treesitter parsers and Mason packages
- gcc, make         compile treesitter parsers
- ripgrep (rg)      picker grep, project-wide word replace
- fd                picker file search
- wl-clipboard      system clipboard on Wayland (xclip on X11)
                   without one of them `clipboard=unnamedplus` yanks fail

Language toolchains
-------------------
Every language below is enabled by default, so a missing toolchain means that
server, formatter or linter fails to install or run. Trim lua/extensions.lua
if you never write the language.

- nodejs + npm      JS/TS and web: vtsls, tailwindcss, cssls, oxfmt, oxlint,
                    markdownlint-cli2, cspell
- python3 + pip     Python: basedpyright, ruff, djlint, write_good
- go                Go: gopls, gofumpt, golangci-lint
- rustup + cargo    Rust: rust_analyzer and rustfmt (`rustup component add
                    rustfmt` if it is missing). cargo also builds blink.cmp's
                    native fuzzy matcher; without it the Lua matcher is used
- luarocks          Lua: lua_ls
- clang             C/C++: clangd and clang-format ship as Mason binaries, the
                    toolchain is only needed for the projects you build

Optional, per feature
---------------------
- opencode CLI      in-editor AI panel (<leader>O); install from opencode.ai
- tmux              lets Navigator.nvim (<C-hjkl>, <C-\>) cross tmux panes,
                    otherwise it moves between Neovim windows only
- imagemagick       Snacks.image: raster images inside buffers
- ghostscript (gs)  Snacks.image: PDF pages
- tectonic          Snacks.image: LaTeX rendering
- wakatime-cli      vim-wakatime time tracking; the plugin downloads its CLI
                    on first use, so installing it yourself is unnecessary

Installed automatically on first launch
---------------------------------------
Everything here comes from lua/extensions.lua:

- plugins         every entry in nvim-pack-lock.json, via vim.pack.add()
- LSP servers     vtsls, html, cssls, tailwindcss, lua_ls, basedpyright,
                  bashls, clangd, rust_analyzer, gopls
- formatters      clang_format, ruff, stylua, oxfmt, markdown-toc,
                  markdownlint-cli2, gofumpt
                  (rustfmt comes from the Rust toolchain, not Mason)
- linters         oxlint, hadolint, write_good, markdownlint-cli2, shellcheck,
                  actionlint, djlint, ruff, codespell, cspell, golangcilint
- treesitter      the 27 parsers in extensions.ts_parsers

Mason prepends ~/.local/share/nvim/mason/bin to Neovim's PATH, so the tools
it installs are not on PATH in a plain shell - call them by full path
(~/.local/share/nvim/mason/bin/<tool>) from scripts.

First run
---------
No manual step is needed: open `nvim` and the installs above run by
themselves. A headless first run (nvim --headless) does not populate the Mason
tools, because mason-lspconfig skips ensure_installed without a UI.

Verify
------
:Mason          browse, add or remove tools outside the lists above
:TSInstallAll   re-run the parser install (also runs on every startup)
:checkhealth    clipboard, LSP, treesitter and provider status
:PackUI         plugin manager - update, delete, inspect (<leader>ps)
